# 📖 Программа для чтения вещественных чисел

Консольная утилита для считывания и обработки вещественных чисел из стандартных потоков ввода или файлов.

## 💻 Сборка и совместимость
* **ОС:** Тестировалось и собиралось под **Ubuntu**. 
* **Портативность:** Должно успешно собираться и под другими дистрибутивами Linux.

## 🛠 Установка зависимостей
Для установки библиотеки **CLI11** выполните команду:
```bash
make install-deps
```

## 🚀 Использование и возможности
* **Потоки ввода:** Реализована работа с потоками (0) и (1), а также с обычными файлами.
* **Справка:** Для получения подробной информации о работе программы запустите её с флагами:
  ```bash
  -h
  --hh
  ```

## 🧪 Тестирование
В корневом каталоге проекта находится скрипт для **генерации файлов с числовой последовательностью**, с помощью которого можно быстро проверить работоспособность программы.
